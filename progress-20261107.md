## Public-release prep: MIT license, GitHub repo, core pinned to the GitHub tag

**Summary.** hotwell-panel is licensed MIT and published as `CodeReclaimers/hotwell-panel`
(public). Its hotwell dependency now points at the public core tag on GitHub,
`CodeReclaimers/hotwell@v0.3.0`, instead of a sibling checkout. Neither package goes to PyPI
(Alan).

**Changes.**
- `LICENSE`: MIT, `Copyright (c) 2026 Alan McIntyre`, copied byte-for-byte from
  `~/TSDDS/LICENSE`.
- `pyproject.toml`: `license = "MIT"`, `license-files`, `authors`, `[project.urls]`;
  setuptools floor 68 → 77 (PEP 639). Dependency
  `hotwell>=0.3,<0.4` → `hotwell @ git+https://github.com/CodeReclaimers/hotwell@v0.3.0`.
  Why: hotwell is not on PyPI, so a bare name resolves against PyPI. It 404s today, but it
  would install whatever a third party later registers as `hotwell`. Cost: the version
  range becomes an exact tag pin, and the panel migration to 0.4.0 must edit the pin.
- `README.md`: core link → GitHub; dev setup drops `uv pip install -e ../hotwell` (the
  hazard flagged in the core's 0.4.0 HANDOFF) and explains why not to do it; License section.
- `HANDOFF.md` "How to run": same `-e ../hotwell` line removed. The historical line 10
  (`../hotwell` commit `9464eb2`) is left as a record.
- `PLAN-panel.md`: added at the repo root, copied from `/home/alan/plant-sim/PLAN-panel.md`
  (the original stays in place). 17 references across Makefile, board.svg, panel.css,
  types.ts, svelte.config.js and the docs pointed at it, and they dangled for anyone
  without the parent directory.

**Decisions (Alan).** Working docs published as-is with history; add PLAN-panel.md; repo
name `hotwell-panel`; MIT holder line as above. Rejected alternatives are recorded in
